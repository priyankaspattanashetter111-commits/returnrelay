# ReturnRelay 2.0 demonstration script

## Four-minute walkthrough

**0:00 — The problem.** A return is more than a deadline: the buyer needs a receipt, a policy, a preparation slot and follow-up evidence. ReturnRelay brings these steps into one accountable workflow.

**0:25 — The workspace.** Register locally. Settings → Load fictional examples. Show Overview and My Purchases. State clearly that the original sample merchants, policies, purchases and refund notice are fictional. Counts and charts are read from your account database.

**0:50 — The evidence.** New Return → Everyday headphones / RR-1042. Progress through product details, confirmed receipt, condition and reason. Show the policy source and version. The fictional rule gives 26 November, 23:59 IST. The scenario clock is fixed at 24 November.

**1:30 — The MCP boundary.** Show the suggested preparation period, which avoids the occupied 17:00–18:00 interval. It is not a merchant pickup. Generate and review the exact recipient, message and reminder. No files exist yet.

**2:00 — Approval and reliability.** Check exact-plan consent and simulated calendar failure. Approve; the real Actions MCP tool errors without committing either local output. Untick failure and approve. Download EML/ICS. Retry: the same pair is returned, without duplicates.

**2:40 — The honest stop.** Select the expired lamp or unclear backpack. The workflow explains the evidence and prevents automatic preparation. Save the review case in tracking. The assistant can explain a decision but cannot authorize it.

**3:05 — Follow-up.** Show the return timeline and Refund Tracker. A fictional merchant notice says processed, while bank credit stays unverified. Explicit user review of a separate document, amount and reference is required to mark credit verified. No bank API is connected.

**3:30 — Real protocol, useful boundaries.** MCP Activity shows three responsive processes, discovered schemas, actual calls, failure, duration and redacted responses. The project uses official SDK stdio, not ordinary function calls disguised as MCP.

**3:50 — Close.** ReturnRelay prepares evidence-backed returns with clear human control. It works without a paid AI key. The next integration work is OAuth providers and provider reconciliation, not bypassing approval.
