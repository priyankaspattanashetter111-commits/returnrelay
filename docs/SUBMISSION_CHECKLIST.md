# Demonstration readiness checklist

- Start the localhost app using README PowerShell commands.
- Register a personal account; load fictional examples explicitly in Settings.
- Rehearse all five README scenarios. Keep merchant notice and bank confirmation separate.
- Check the exact outgoing draft and preparation reminder; do not call it a pickup booking.
- Show actual MCP tools, schemas, calls and a safe failure/retry.
- Run scripts/run_tests.ps1 before recording changes.
- Review README limitations. Do not claim live OAuth, independent bank verification, production security or measured savings.
- Inspect git diff. Keep .env, databases, uploads, virtual environments and logs out of commits.
- Publish source only when ready. No Git push, event submission, video upload or cloud deployment was performed by the implementation task.
- Confirm current event requirements directly with organizers; this repository makes no claim about deadlines or sponsor qualification.
